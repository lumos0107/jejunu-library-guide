# 제주대 도서관 활용 가이드 · 세 번째 버전(v3 ①)

로그인 없이 학생의 상황과 서비스 이름으로 도서관 정보를 찾아보는 비공식 안내 웹사이트입니다.

## 실행

**index.html을 브라우저로 열면 됩니다.** 서버, 설치, API 키, 가입 필요 없음. 공식 링크 방문 시 인터넷 연결 필요. index.html, styles.css, data.js와 js 폴더는 같은 위치에 두세요.

## 현재 범위

- 이용 가이드: 48개(책 반납 안내 추가)
- 논문·자료 사이트(전자정보원): 98개 (공식 원목록 97행 → 중복 병합 96개 + 전자책 목록 추가 2개)
- 공식 사이트 메뉴: 상위 6개 메뉴의 하위 89개
- 전체 검색 대상: 235개 안내 레코드. 서로 다른 기능 235개를 뜻하지 않으며 같은 서비스가 서로 다른 안내 유형에 표시될 수 있습니다.

## 기능

- 전체 / 이용 가이드 / 전자정보원 / 공식 메뉴 검색 범위 선택
- 이름·설명·용도·분야·공식 설명·키워드·이용단계 검색 (기본 키워드 검색, AI 의미 검색 아님)
- 6가지 상황, 학부생 필터(대학원 대상 안내가 있을 때만 표시), 적용 중인 필터 표시와 하나씩 해제
- 전자정보원 분야·공식 분류·공개자료/시범서비스/범위 확인 필요 필터
- 공식 메뉴 상위 분류 필터
- 상세 맨 위에 공식 버튼·찾는 방법·대상/비용/인증 요약, 출처와 확인일이 붙은 사실, 공간 위치, 실제 매뉴얼·자료 목록 링크
- 시험기간 24시간 개방 같은 "지금 이 시기" 공지(기간이 지나면 자동으로 숨김)
- 페이지당 12개 + 더 보기
- 책 상태별 해결 경로, 관련 가이드, 모바일 반응형

## 안내 확인 수준

상세 가이드 / 전자정보원 공개 목록 / 공식 메뉴 위치를 명확히 구분합니다. 모든 공식 하위본문을 재작성한 완성본은 아닙니다. 실제 로그인, 개인현황, 대출·예약·신청, 외부 서비스 이용, 실시간 좌석·운영 상태는 시험하지 않았습니다.

## 파일

- index.html / styles.css / js/(lib.js·app.js) / data.js: 웹사이트. data.js는 data/*.json으로 만든 생성물(`python tools/build_data.py`)
- tools/, tests/: 생성·검사 도구와 Playwright 테스트(docs/DEV.md)
- docs/v3/: 세 번째 버전 기획(PRD·리서치·계획·교차 평가)
- docs/PLAN.md, RESEARCH.md: 최초 기획·조사
- docs/MENU-AUDIT.md: 확장 범위와 전체 메뉴 대조
- docs/*-raw.json, official-menu-inventory.json: 공개 자료 조사 기록
- docs/QA.md: 최초 검사
- docs/QA-v2.md: 두 번째 버전 검사
- docs/version1/: 첫 버전 보관

## 개인정보·배포

학교 계정·개인정보를 입력받거나 저장하지 않습니다. 이 사이트 자체에는 로그인이 없고 실제 서비스는 별도 인증이 필요할 수 있습니다. 현재 로컬 시안이며 공개 배포하지 않았습니다.
