# 제주대학교 모바일 도서관 앱 둘러보기 (2026-10-14)

사용자 질문 "도서관 앱도 있거든 이거 설치해서 조작할 수 있어?"에 따라 안드로이드 에뮬레이터(Pixel 7, Android 15, Google Play)에 앱을 설치하고, 사용자가 직접 로그인한 뒤 **보기만** 했다. 좌석 발권·예약·메시지·메모 작성 같은 상태를 바꾸는 동작은 하지 않았고, 이용증(학번·바코드)·대출 목록·메모보드 글은 열거나 기록하지 않았다.

- 앱: Play 스토어 '제주대학교 모바일 도서관', 설치 후 아이콘 이름 '제주대학교 도서관', 버전 2.4.2
- 화면의 좌석 수는 그 시각의 화면 값이다. 공식 웹 안내와 다른 곳은 따로 적었다.

## 첫 화면

- 위: 설정, 이용증(ID), 학습시간·오늘의 활동(대출권수·방문횟수), MY PAGE
- 메뉴 9개: 도서검색, 도서대출, 나의 자리, 일반열람실, 그룹학습실, 개인 캐럴, 메이커 스튜디오, 메모보드, 메시지

## 일반열람실(좌석 발권)

도서관 → 층을 고르면 열람실마다 `사용 중/전체`와 `잔여좌석`이 실시간으로 보인다(로그인한 앱 안에서만. 공식 웹에는 실시간 좌석 화면이 없다).

| 도서관 | 층 | 열람실(전체 좌석) |
|---|---|---|
| 중앙도서관 | 1F | PCZONE PC석(12), PCZONE 노트북석(20), 제주자료실(44) |
| 중앙도서관 | 2F | 1열람실(420) |
| 중앙도서관 | 3F | 2열람실(404), 3열람실(62), 4열람실(74) |
| 중앙디지털도서관 | 1F | 정보검색존(40), **DVD ZONE(1인) 8**, **DVD ZONE(2인) 8**, 노트북열람실(24) |
| 중앙디지털도서관 | 2F | 2층 스마트열람실 A(12)·B(40)·C(17) |
| 중앙디지털도서관 | 3F | 3층 스마트열람실 A(18)·B(12)·C(17)·D(32) |
| 교육대학 도서관 | 3F | 열람실A(216), 열람실B(66) |

- 공식 웹 '일반열람실' 안내(#/service/facility/readingroom)는 중앙도서관 PC석 11·노트북석 20, 3열람실 PC석 16·노트북석 24, 교대분관 318석으로 적어 앱과 숫자가 조금 다르다(앱: PC석 12, 3열람실 62, 교대 216+66=282).
- 중앙디지털도서관 좌석(정보검색존·DVD ZONE·노트북열람실·스마트열람실)은 공식 웹 일반열람실 안내 표에 없다.

## 그룹학습실

- 6인실 204~207호, 8인실 208~210호, 9인실 201호, 10인실 202호, 12인실 203호
- 공식 웹 표는 201호 정원 8(최소 4)로 적어 앱의 '9인실'과 다르다.
- 오늘부터 7일(10/14~10/20) 날짜를 고르고, 방별 30분 단위 칸에 '예약가능·예약 중·예약 불가'가 보인다.

## 개인 캐럴

- C1~C7, 날짜별 09:00~20:00 한 칸, 7일 앞까지 날짜 선택. (공식 안내: 대학원생·교직원 대상. 앱 화면에는 대상 표시가 없다.)

## 메이커 스튜디오

- 제작실, 편집PC(PC1, PC2(MAC))

## 메모보드

- 일반 보드, 분실물 보드, 그룹 보드(글은 열지 않음). 공식 유실물 안내의 "'제주대모바일학생증' > 메모보드 > 유실물보드"와 같은 메뉴다.

## 사이트 반영

- 영화 DVD 보기: 앱 일반열람실 → 중앙디지털도서관 → 1F에서 DVD ZONE 잔여 좌석을 확인하는 단계 추가(발권은 해 보지 않아 발권 방법은 현장 확인으로 둠, GPT 검토 반영). DVD ZONE과 미디어라운지가 같은 곳인지는 확인하지 못함
- 일반열람실 좌석: 앱에서 실시간 잔여 좌석을 볼 수 있음, 중앙디지털도서관 좌석도 앱에 있음
- 모바일 도서관 앱: 첫 화면 메뉴와 설치 후 아이콘 이름
