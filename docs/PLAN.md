# 방향성과 첫 버전

## 목표
학생이 서비스 이름을 몰라도 필요한 서비스를 발견하고, 이용 대상·경로·조건을 이해한 뒤 공식 서비스로 이동할 수 있게 한다. 공식 홈페이지를 대체하거나 로그인·예약 시스템을 복제하지 않는다.

## 사용자 흐름
상황 선택 또는 키워드 검색 → 서비스 설명 → 대상·비용·로그인·제한 확인 → 단계별 이용 방법 → 공식 안내/앱/현장 연결.

## 분류
1. 과제·발표
2. 책·자료
3. 공부 공간
4. 시설·편의
5. 독서·시험 준비
6. 첫 이용·도움

## 검증할 가설
- 학생이 서비스 존재를 모르는가?
- 이름만 보고 용도를 이해하지 못하는가?
- 홈페이지·앱·외부 사이트 이동에서 막히는가?
학생 인터뷰로 인지 서비스, 사용 경험, 포기한 이유를 확인한다. 현재 사용자 조사 결과는 없다.

## 다음 작업
- 학생 5~8명과 서비스 발견 과제 수행 후 검색 표현·혼란점 기록
- 전자정보원 개별 서비스 데이터 확대: 용도/원문/서지 DB 구분, 구독/공개/Trial 구분
- 공식 화면 캡처를 이용한 상세 튜토리얼 작성 (현재 화면 캡처 튜토리얼 없음)
- 상호대차 대출기간 등 상충 안내 담당자 확인
- 콘텐츠 수정 제보와 정기 확인 절차 설계
- 공개 배포 전 링크·사용 조건·기관 표기·접근성 재검수

## 의도적으로 제외
회원가입, 계정 저장, 대출/예약 대행, 실시간 좌석정보, 자동 수집, 신청 폼, 확인되지 않은 혜택·무료 약속.
