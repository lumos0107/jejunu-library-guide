# 두 번째 버전 전체 점검

점검일: 2026-10-13 (자료 기준일 2026-10-12)

## 점검 방법

네 갈래로 나눠 진행했다. 사이트 파일은 수정하지 않았다.

| 갈래 | 방법 |
|---|---|
| 코드 | Playwright(file://)로 동작 시나리오 실행, Node로 데이터 교차 검사, WCAG 대비 계산 |
| 데이터 | data.js 234개 레코드 분석, app.js와 같은 방식으로 검색어 66종 실행 |
| 사용 흐름 | 페르소나 3명 × 과업 3개, 데스크톱 1440px · 모바일 390px, 스크린샷 확인 |
| 링크 | 고유 URL 242개를 HTTP로 확인하고, 해시 경로 94개는 브라우저로 비로그인 접속 |

## 잘 되어 있는 것

- 콘솔 오류 0건. id 234개 고유, 필수 필드 누락 0, 비 HTTPS·javascript 링크 0.
- 스스로 정한 신중 표기 규칙을 지킴: 상호대차 기간 상충, 교정은 유료 협약가, 캐럴은 대학원 대상, 사물함 조건, 원문복사 지원금의 개인 부담, CAS 연도 미표기.
- 링크 242개 중 끊긴 것은 2개뿐이고, 둘 다 공식 사이트 쪽 문제.
- 첫 화면 메시지, 질문형 상황 카드, 말투, 색·레이아웃이 일관됨.
- 성능 문제 없음: 로컬 DCL 12.7ms, 입력 한 번 렌더 약 1ms.

## 2. 검색이 학생 말을 못 알아들음

- 0건이 나오는 검색어: 조별과제, 조모임, 프린터, 영어논문(붙여 씀), PPT, APA, SPSS, 엑셀, 콘센트, 토익, 취업, "팀플 할 곳", "논문 찾기", “통계”(둥근 따옴표).
- 정답을 못 찾는 검색어: "열람실 예약"과 "좌석 예약"에서 `seat`이 빠지고, "책 반납"은 반납 안내 자체가 없다.
- 관련도 정렬이 없다: "학위논문"은 해외 학술자료가 먼저, "시험기간"은 야간버스가 먼저 나온다.
- 같은 문장이 결과를 덮는다: "교외접속" 98건, "인증" 110건, "메뉴" 95건.
- 같은 서비스가 가이드·전자정보원·공식 메뉴로 3중 표시된다(표절 6건, 참고문헌 4건). 메뉴 89개 중 33개가 가이드와 같은 주소다.
- 숨은 필터 때문에 0건: 상황 카드를 누른 뒤 검색하면 그 상황 안에서만 찾는데, 빈 결과 화면에 이유가 나오지 않는다.
- 상황 탭을 누르면 입력해 둔 검색어가 말없이 지워진다.

## 3. 마지막 한 걸음이 부족함

- 전자정보원 98개 전부가 개별 페이지가 아니라 전체 목록 첫 화면으로 간다(가이드 6개 포함 103개 레코드). 학생이 목록에서 이름을 다시 찾아야 한다.
- 위치(층·호실), 앱 다운로드, 실제 예약 경로가 없다. 예: 프린터 위치는 공식에 "중앙 3층 3열람실"로 나와 있다.
- 상세창의 공식 링크 버튼이 데스크톱에서도 항상 화면 밖에 있다(내용 816~1,073px, 화면 763px).
- 비교가 필요한 서비스를 오가며 봐야 한다: 에디티지/이나고, 카피킬러/Turnitin, EndNote/RefWorks.
- 이용 단계 142개 중 46개(32%)가 "…확인"으로 끝난다. 11개 가이드는 3단계 중 2개 이상이 "확인"이다.

## 4. 모바일·접근성

- 모바일에서 검색창이 화면 맨 위로부터 2,061px 아래에 있다(전체 6,584px). 헤더 메뉴가 숨는데 대체 메뉴가 없다.
- 탭 영역이 33~37px로 44px보다 작다.
- 상태가 URL에 남지 않는다: 뒤로가기를 누르면 사이트를 벗어나고, 검색 결과나 상세 링크를 공유할 수 없다.
- 포커스: '더 보기'를 끝까지 누르면 포커스가 사라진다. 상황 카드를 누른 뒤에도 포커스가 위에 남는다.
- 동작 줄이기 설정을 무시하는 smooth 스크롤이 있다.
- 색 대비: muted 글자 4.31~4.48(AA 4.5 미달), 포커스 링 2.58(3:1 미달).
- 구조: button 안에 h3가 있고, 탭 묶음에 role이 없다.

## 5. 쉬운 말·화면 정리

- 학생에게 낯선 용어: 전자정보원, 공식 메뉴 위치, 제공 표시, 국외DB.
- 범위 안내가 내부 점검 말투다("원목록 97개에서 중복 1개를 합친 96개 + 2개").
- 가이드 47개 모두에 '세부 조건 확인' 배지가 붙어 정보가 없다.
- 이용 대상의 '대학원생(전체 안내)'는 '전체'와 결과가 같다.
- 상세창 하나에 면책 문구가 3번 나온다.

## 6. 유지보수

- app.js는 39줄에 14KB, styles.css는 3줄로 압축되어 있다. CSS 규칙 일부가 두 번 정의되어 있다.
- 테스트가 없다. QA-v2의 수동 수치 검사를 자동화할 수 있다.
- docs/*-raw.json에서 data.js를 만드는 스크립트가 없어서 둘이 어긋날 위험이 있다.
- relatedMap과 bookCases는 내용 데이터인데 app.js 안에 있다.
- 값 표기가 제각각이다: channel 31종, login 20종, cost 19종. cost는 55%가 "공식 안내 확인"이다.
- 오타(공식 원문 그대로): KISA 괄호, "Sage Premire", "최업정보", "트랜드". 매뉴얼/메뉴얼/Manual, LIST/리스트 표기도 섞여 있다.
- docs/RESEARCH.md에 "세부 서비스 33개"가 남아 있다(현재 47개).
- 보안: 텍스트 escape는 일관되지만 `data-open` id와 `s.source` href에는 검사가 없다(현재 데이터로는 안전).
