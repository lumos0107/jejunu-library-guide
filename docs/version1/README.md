# 제주대 도서관 활용 가이드

로그인 없이 학생의 상황에서 도서관 서비스를 찾아보는 비공식 안내 웹사이트 1차 시안입니다.

## 실행

이 폴더의 **index.html을 브라우저로 열면 됩니다.** 설치, 서버, API 키, 회원가입이 필요 없습니다. 인터넷 연결은 공식 서비스 링크 방문 시 필요합니다. index.html, styles.css, data.js, app.js를 같은 폴더에 두세요.

## 구현된 기능

- 6가지 상황 분류, 33개 서비스 안내
- 서비스 이름·용도·키워드 검색
- 학부생/대학원생 대상 필터
- 책의 상태별 해결 경로 6가지
- 상세 이용 단계, 로그인 조건, 비용 안내, 주의점, 공식 출처
- 관련 서비스 연결, 모바일 반응형, 키보드 사용 및 기본 접근성

## 파일 구조

- index.html: 화면 구조
- styles.css: 반응형 스타일
- data.js: 서비스 데이터 (window.LIBRARY_GUIDE)
- app.js: 검색, 필터, 상황별 추천, 상세창
- docs/PLAN.md: 기획과 다음 단계
- docs/RESEARCH.md: 조사 범위, 출처와 확인 필요 사항

## 안내 및 범위

공개 안내 확인일: 2026-10-12. 공식 도서관 사이트가 아니며 학교와 제휴한 서비스가 아닙니다. 이 사이트에는 사용자 로그인·학교 계정 입력·개인정보 수집·예약/대출 실행·실시간 좌석/운영 상태 조회·분석 추적이 없습니다. 실제 도서관 서비스는 학교 로그인이나 별도 등록이 필요할 수 있습니다. 외부 접속 및 로그인 후 기능은 시험하지 않았습니다.

## 배포

네 파일을 정적 호스팅에 올리면 공개 안내 사이트로 배포할 수 있습니다. 현재는 로컬 시안이며 공개 배포하지 않았습니다.
