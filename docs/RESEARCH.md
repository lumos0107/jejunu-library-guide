# 공개 안내 조사 기록

확인일: 2026-10-12. 제주대학교 중앙도서관 공식 홈페이지의 전체 메뉴 및 주요 공개 안내를 브라우저 스냅샷으로 조사했다. 로그인 후 기능과 외부 서비스 실제 작동은 확인하지 않았다. v1 당시 세부 서비스 33개(현재 48개)는 전자정보원을 용도별 묶음으로 정리한 안내 수이며 공식 서비스 수와 동일하지 않다.

## 공식 메뉴
- 자료검색: 통합검색, 소장자료, 전자자료
- 연구학습지원: 연구지원, 논문작성지원, 학술정보활용교육
- Collections: 신착/인기, 추천, 디지털 컬렉션
- 도서관서비스: 자료이용, 시설이용, 프로그램, 이용자별 안내
- 도서관안내: 소개, 열린광장
- My Library: 대출/신청 현황, 개인정보, 내 서재, 제재현황

## 꼭 구분할 사항
- 전자정보원 목록은 97개 항목으로 표시되었지만 CAS BioFinder 중복, 공개자료, 시범서비스가 포함되어 있어 정식 구독 서비스 97개라고 표현하면 안 된다.
- 학부생은 캐럴 이용 불가; 그룹스터디룸/메이커 스튜디오는 재학생·교직원 대상.
- 사물함은 재학생 학기별 추첨, 휴학생·연체도서 보유자 신청 불가.
- 원문복사·상호대차는 학생 합산 연간 10만원 지원 안내가 있으나 초과금·연체료·예산 소진 시 개인 부담 가능.
- 상호대차 대출기간이 14일과 도착일부터 3주로 서로 다르게 적혀 있다. 담당자 확인 전 단정하지 않는다.
- 외국어 교정은 무료가 아닌 협약가 서비스.
- 운영시간·행사·야간버스는 이용 직전 최신 공지 확인.
- 공개 목록에 안내되었다는 것과 사용 자격/무료/실제 접속 확인은 다르다.
